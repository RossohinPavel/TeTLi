# TelegramTODOList

Телеграм бот реализующий функционал всем известного листа заметок.

## Основные возможности Бота

### Создание задачи

* При отправке текста боту появляется отслеживаемая задача.
* Задачку можно создать путем отправки боту аудио сообщения.

### Редактирование задачи

* У задачи можно поменять содержание нажав на кнопку изменить. Для изменения введите новый текст и нажмите сохранить. 
При нажатии на кнопку отмена сбрасываются изменения, если они были, до предыдущих

### Выполнение задачи

* Было бы странно, если задачу нельзя было выполнить. (Можно, конечно, удалять сообщения, но так быстрее.) В будущем, возможно, появиться статистика для пользователей с различной информацией о задачках.
* Удаленное сообщение не означает, что задача была выполнена. Нужно именно нажать на выполнить.

### Напоминание о задачах

* Так как удалять сообщения в Телеграмме бот может только в течение 48 часов, то задачи автоматически обновляются спустя это время. В будущем, возможно, появится более сложная логика.


## Запуск

Для запуска необходим docker

Инструкция

1) Клонировать проект
2) Находясь в корне проекта - docker-compose build
3) Как билд закончится, обновить данные базы данных
4) Запуск по команде docker-compose up -d

* Команды для работы с докером
docker-compose ps - выведет список запущенных контейнеров
docker-compose logs <app> - выведет лог приложения <app>. Без аргумента - логи всех приложенией.
docker-compose exec <app> <command> - выполнить команду (как в терминале) для приложения <app>.
Например, узнать список установленных пакетов python
docker-compose exec app pip list
