# Таблицы базы данных

#### Сообщения

| Названите столбца    | Тип данных                 | Описание                                                         |
| -------------------- | -------------------------- | ---------------------------------------------------------------- |
| id                   | int                        | ид записи                                                        |
| message_id           | int                        | ид сообщения в телеграмме                                        |
| task_id              | int                        | Связь с задачей                                                  |
| hide_date            | timestamp with timezone    | Время скрытия сообщения.<br>Кроме скрытия, удаляет запись из бд. |


#### Задачи

| Названите столбца    | Тип данных              | Описание                                                                             |
| -------------------- | ----------------------- | ------------------------------------------------------------------------------------ |
| id                   | int                     | ид записи                                                                            |
| telegram_id          | int                     | ид пользователя в телеграмме                                                         |
| content              | str                     | Текст сообщения (задачи)                                                             |
| status               | int                     | Статус задачи. <br>0 - в работе, 1 - выполенна. 2 удалена.                           |
| start_date           | timestamp with timezone | Время начала отслеживания задачи.                                                    |
| interval             | int                     | Время в секундах описывающее временной интервал, который должен прибавляться к start |
| live_time            | int                     | Время в секундах, которое может жить задача (Время существования сообщения)          |


Тип оповещения определяется на основе заполнения атрибутов start и interval
- Если не заполнен start_date - Без Оповещения
- Если заполнен start_date - Разовое оповещение
- Если заполнен и start_date и interval - Постоянное оповещение.

Отрисовка задач:
Это сама celery-задача, которая запускается раз в 5 минут.
выбираем все задачи, у которых now <= start_date <= now + 5min.
создаем celery-задачи на рендер с задержкой относительно start_date. 
hide_date = start_date + interval. 
Если есть interval, то обновляем start_date.

Скрытие задач:
Это сама celery-задача, которая запускается раз в 5 минут.
Выбираем все сообщения, где now - 5 min <= hide_date <= now + 5 min
Создаем celery-задачи на скрытие. Скрытие, помимо запроса к телеге, удаляет запись из таблицы сообщений.

Ручной рендер.
- Показываем задачи в телеге, но схема сложнее. Выбираем все скрытые задачи и рендерим их. hide_date = now + live_time. Если hide_date > start_date, то hide_date = start_date. Не важно, повторяется эта задача или нет.



# **Работа сервиса**

Регистрации пользователей в боте нет. Можно сразу пользоваться всем функционалом

> Создание задачи

Задача может быть создана 3мя способами:
1) Отправка текстового сообщения боту.
2) Отправка аудио-сообщения боту.
3) Конструктор задачи в реакт-приложении

Задачи в первом и втором случае создаются в соответсвии с настройками по умолчанию.
При создании задачи происходит запись в базу данных.

> Интерфейс работы с задачей в боте.

Бот предоставляет упрощенный интерфейс (клавиатуру) для работы с задачами. Задачу можно:
- Выполнить. Процесс выполнения задачи удаляет сообщение из бота и вносит соответствующие правки в базу данных.
- Изменить. Кнопка открывает реакт-приложение для изменения задачи. Подробнее ниже.

> Изменение задачи.

Изменение задачи происходит через реакт-приложение.
Можно:
- Поменять текст задачи.
- измениеть тип и дату напоминания, время отображения задачи.

> Удаление сообщения

Скрытия задачи нет, но можно удалить сообщение бота. Удаление сообщения бота = скрытие задачи, т.е. приводит к удалению записи из таблицы сообщений.


# Меню

Меню в боте дает возможность для следующих функций:
- Кнопка для показа скрытых задач (Скрытая задача - задача, которая не выполнена, но в настоящий момент не отображается в боте. При вызове скрытых задач должны обновляться временные метрики.)
- Помощь - открывает реакт-приложение с текстом для описания функционала приложения.
- Открывает реакт-приложение для отображении статистики пользователя.
- Открывает реакт-приложение для создания задачи с углубленной настройкой.


# Задача

> Текст задачи - текст, на который накладываются ограничения Телеграмм в плане количества символов и формата текста.

> Тип напоминания.

Для каждой задачи можно установить тип напоминания. Он может быть 3х видов:
1) Без напоминания. Значение - 0. Задача в таком виде создается, отправляется в бот и существует там установленное время жизни. После того, как время жизни заканчивается, задача из бота скрывается. Ее можно снова вернуть в бот по кнопкам в меню.
2) Разовое напоминание. Значение - 1. 


# Статистика

Задачи только попадают в таблицу и не удаляются из нее. Статистика пользователя считается на основе агрегатных запросов к таблице по задачам. 
Статистика должна выводить:
- Количество отслеживаемых задач, которые так или иначе находятся в работе.
- Количество выполненных задач
- Количество удаленных задач
- ?? Количество отложенных задач


# Кейсы постановки задач.

> Через бот

Сообщение, которое было отправлено боту удаляется.
Создается задача, у которой тип напоминания - повторяющаяся. Дата напоминания - время, когда задача была отправлена в бот. Время жизни - 2 дня (максимальное время, которое телега может помнить сообщение для его удаления.)
Сразу эту задачу отображает в боте.

> Через реакт приложение

Можно настроить тип и время отображения, длительность отображения. Показать сразу(стоит по умолчанию) или нет.
